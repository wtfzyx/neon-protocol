# 霓虹协议 · Neon Protocol

3D 科技风机甲对战 FPS 网页游戏，纯前端实现：Three.js（r152）+ WebAudio 现场合成音效，所有画面用基础几何体 + 发光材质搭建，无任何外部模型 / 贴图 / 音频文件。

## 功能（七期全部完成）

- P1 框架：科技风竞技场（发光网格地面 / 霓虹柱子 / 雾效）、第一人称、WASD 移动、鼠标视角（Pointer Lock）、左键射线射击、准星
- P2 身体：生命 100、Shift 冲刺、Ctrl 滑铲、空格跳跃、体力自动回复、血条 + 体力条
- P3 敌人：5 个机器人，三状态 AI（随机路点巡逻 → 发现玩家追击开枪（有命中率）→ 脱战回巡逻），敌人血条、打中闪白、死亡爆炸粒子、延迟重生
- P4 成长：命中 +5 经验、击杀 +20 经验、升级回满血、枪械伤害 +10%、等级 + 经验条
- P5 武器：步枪（连发）/ 霰弹枪（散射 5 发）/ 狙击枪（高伤慢速），按 1/2/3 切换，各自射速、弹匣、换弹、枪声；狙击枪按 G 开镜
- P6 音效播报：敌人死亡爆炸音、玩家死亡低沉音、连杀播报（3 双杀 / 5 三杀 / 10 大杀特杀）
- P7 结算：死亡后显示本局击杀数、存活时间、最终等级，按 R 重开

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角（点击开始后锁定） |
| 左键 | 射击（步枪按住连发） |
| Shift / Ctrl / 空格 | 冲刺 / 滑铲 / 跳跃 |
| 1 / 2 / 3 | 步枪 / 霰弹枪 / 狙击枪 |
| R | 换弹（死亡结算界面按 R 重开） |
| G | 狙击枪开镜 |
| Esc | 释放鼠标 / 暂停 |

## 运行方式

### 网页版

直接双击 `index.html` 即可（Three.js 会优先用同目录的 `three.min.js`，没有则自动退回 CDN，需要联网）。

### 桌面版（Electron）

```bash
npm install        # 安装依赖
npm start          # 运行游戏
npm run dist       # 打包出 Windows 安装程序（dist 目录）
```

打包完成后，`dist` 目录下会有：
- `NeonProtocol Setup x.x.x.exe`（安装版）
- `NeonProtocol x.x.x.exe`（便携版，免安装直接双击玩）

## 技术

- Three.js r152（全局 THREE，非 ES module）
- 全部画面：Box / Cylinder / Plane / Torus 等基础几何体 + 发光材质
- 全部音效：WebAudio 振荡器 + 噪声现场合成
- 单个 `index.html` 即完整游戏
