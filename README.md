# 霓虹协议 · Neon Protocol

3D 科技风机甲对战 FPS 网页游戏，纯前端实现：Three.js（r152）+ WebAudio 现场合成音效，所有画面用基础几何体 + 发光材质搭建，无任何外部模型 / 贴图 / 音频文件。

当前版本：**v1.1**（在 v1.0 的 P1~P7 基础上，新增 P0~P6 迭代）

## 功能（七期全部完成）

- P1 框架：科技风竞技场（发光网格地面 / 霓虹柱子 / 雾效）、第一人称、WASD 移动、鼠标视角（Pointer Lock）、左键射线射击、准星
- P2 身体：生命 100、Shift 冲刺、Ctrl 滑铲、空格跳跃、体力自动回复、血条 + 体力条
- P3 敌人：5 个机器人，三状态 AI（随机路点巡逻 → 发现玩家追击开枪（有命中率）→ 脱战回巡逻），敌人血条、打中闪白、死亡爆炸粒子、延迟重生
- P4 成长：命中 +5 经验、击杀 +20 经验、升级回满血、枪械伤害 +10%、等级 + 经验条
- P5 武器：步枪（连发）/ 霰弹枪（散射 5 发）/ 狙击枪（高伤慢速），按 1/2/3 切换，各自射速、弹匣、换弹、枪声；狙击枪按 G 开镜
- P6 音效播报：敌人死亡爆炸音、玩家死亡低沉音、连杀播报（3 双杀 / 5 三杀 / 10 大杀特杀）
- P7 结算：死亡后显示本局击杀数、存活时间、最终等级，按 R 重开

## v1.1 迭代（P0~P6）

- **P0 暂停修复**：ESC / 开始界面 / 任何弹窗显示期间，游戏世界完全冻结（敌人、子弹、命中判定、计时器全部停止，只保留渲染）
- **P1 数值与打击感**：伤害数字飘字（随距离自适应大小）、±20% 伤害浮动、15% 暴击（×1.5 橙红大字）、酒红溅血、爆头判定 + 低沉“嘭”声
- **P2 Boss 战**：连杀 10 触发「霓虹·大圣」——黄昏水面场景（镜面浅水 / 落日 / 枯树剪影 / 浓雾），Boss 血条，三种攻击轮换（挥棍 55 / 冲撞 50 / 棍气波 40，间隔 1.6s），Boss 战死亡按 R 重开本局
- **P3 Boss 奖励**：击败 Boss 永久生命上限 +20% 并回满、全武器伤害 +10%；回归后普通敌人大幅增强（血量 ×2、伤害 ×1.5、移速 +30%、命中率 +20%，与地狱难度乘算叠加）
- **P4 每 5 级强化三选一**：生命上限 +10~30 / 体力回复 +25% / 武器伤害 +5~15%
- **P5 15 级武器专精**：步枪（伤害 +40% 射速 +25%）/ 霰弹（伤害 +40% 弹丸 +2）/ 狙击（伤害 +50% 换弹 -40%）
- **P6 20 级路线选择**：继续发育 / 地狱难度（敌人血量 ×3、伤害 ×2、移速 +50%，击杀经验 ×2）
- **扩展 · 25 / 35 级专属武器**：金色弹窗「请选择你的专武」三选一（步枪伤害再 +10% / 霰弹打击速度 +12% / 狙击打击概率回血），25 级和 35 级各一次，与强化弹窗排队显示

所有弹窗（强化 / 专精 / 路线）共用一套排队系统，排队依次显示、绝不重叠；暂停期间世界完全冻结。

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角（点击开始后锁定） |
| 左键 | 射击（步枪按住连发） |
| Shift / Ctrl / 空格 | 冲刺 / 滑铲 / 跳跃 |
| 1 / 2 / 3 | 步枪 / 霰弹枪 / 狙击枪 |
| R | 换弹（死亡结算界面按 R 重开） |
| G | 狙击枪开镜 |
| Esc | 释放鼠标 / 暂停 |

## 运行方式

### 网页版

直接双击 `index.html` 即可（Three.js 会优先用同目录的 `three.min.js`，没有则自动退回 CDN，需要联网）。

### 桌面版（Electron）

```bash
npm install        # 安装依赖
npm start          # 运行游戏
npm run dist       # 打包出 Windows 安装程序（dist 目录）
```

打包完成后，`dist` 目录下会有：
- `NeonProtocol Setup x.x.x.exe`（安装版）
- `NeonProtocol x.x.x.exe`（便携版，免安装直接双击玩）

## 技术

- Three.js r152（全局 THREE，非 ES module）
- 全部画面：Box / Cylinder / Plane / Torus 等基础几何体 + 发光材质
- 全部音效：WebAudio 振荡器 + 噪声现场合成
- 单个 `index.html` 即完整游戏
## 自动更新

安装版（Setup）内置自动更新：每次启动会检查 GitHub Release 的新版本，发现更新会提示一键重启升级。便携版（单文件 exe）不支持自动更新，属于 Electron 限制。
